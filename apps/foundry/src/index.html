NeoSmartUI Foundry

Built for humans.
Structured for agents.

NeoSmartUI is the AI-first neo-brutalist UI system. This Foundry is the public proof surface for one canonical architecture: Components → Blocks → Pages → Applications.

v0.1 Foundation

The Foundry is currently establishing canonical source, machine-readable authority, migration provenance, safe CI, and generated deployment boundaries before bulk UI migration.

Permanent rules

  • Restart the architecture, not the knowledge.
  • Source once. Demonstrate everywhere.
  • Pressure, not levitation.

Flavor and vertical galleries are intentionally not simulated before their shipping engines exist.
